# v1.8.0 Planning: ZIP Deck Support

**Status:** ✅ COMPLETE - Released 2025-01-25  
**Branch:** `feature/zip-deck-support` → merged to `master`  
**Release:** v1.8.0

## Overview

Add support for importing complete deck packages as ZIP files, including card images. This makes it trivial for users to install decks from the obsidian-tarot-decks repository.

## Goals

- **User Experience:** One-click deck installation (download ZIP, import)
- **Bundle Support:** ZIP contains deck.json + optional images
- **Backward Compatibility:** Existing JSON import still works
- **Deck Repository Integration:** Works seamlessly with obsidian-tarot-decks releases

## User Workflow

```
1. User downloads elder-futhark.zip from obsidian-tarot-decks releases
2. Settings → Deck Management → "Add deck"
3. Selects the ZIP file
4. Plugin extracts deck.json and images to vault
5. Deck ready to use immediately
```

```
├── README.md          # Optional (for reference)
└── cards/             # Optional
    ├── fehu.png
    ├── uruz.png
    └── ...
```

### Storage Strategy

**✅ IMPLEMENTED:** Vault-based storage (hybrid approach)
```
.obsidian/plugins/tarot-practice/
└── decks/
    └── elder-futhark/
        └── deck.json                    # Config only

Templates/Tarot/Decks/                   # Default vault location
└── elder-futhark/
    └── cards/
        ├── fehu.png
        └── ...
```

**Benefits:**
- Images in vault work with Obsidian wikilinks `![[path]]`
- Clean separation: config in plugin dir, assets in vault
- Respects user's template base folder setting
- Portable deck.json files (relative paths)
- Path resolution at render time

### Libraries Needed

- **JSZip** - ZIP file handling (https://www.npmjs.com/package/jszip)
- Already used in Obsidian ecosystem, well-maintained

### Edge Cases

- ZIP without deck.json → Error with clear message
- ZIP with invalid deck.json → Validate before extraction
- Deck ID collision → Prompt user to rename or overwrite
- Large ZIP files → Show progress, handle async
- Corrupted ZIP → Catch errors, clean up partial extraction
- ZIP with absolute paths → Sanitize to prevent directory traversal
