# v1.3.0 Template System Overhaul - Development Plan

## Overview
Replace inline template editors with a hybrid system: built-in defaults + optional file-based customization.

## Design Philosophy
- **Simple by default**: Built-in templates work out of the box
- **Advanced when needed**: File-based templates for customization
- **Backward compatible**: Migrate existing inline templates to files

```typescript
  if (this.settings.useCustomDailyTemplate && this.settings.customDailyTemplatePath) {
    try {

    } catch (error) {
      new Notice('Failed to load custom template, using built-in');

    }
  }

}
```

### Phase 4: Migration System

**4.1 Detect Template Folder**
- File: `src/TemplateFolderDetector.ts`
  ```typescript
  class TemplateFolderDetector {
    detectTemplateFolder(app: App): string | null {
      // 1. Check Templater plugin
      const templaterSettings = this.getTemplaterSettings(app);
      if (templaterSettings?.folder) return templaterSettings.folder;
      
      // 2. Check Core Templates plugin
      const coreTemplatesSettings = this.getCoreTemplatesSettings(app);
      if (coreTemplatesSettings?.folder) return coreTemplatesSettings.folder;
      
      // 3. Check common conventions
      if (app.vault.getAbstractFileByPath('Templates')) return 'Templates';
      if (app.vault.getAbstractFileByPath('templates')) return 'templates';
      
      // 4. Fallback to vault root
      return null;
    }
  }
  ```

**4.4 Trigger Migration**
- In `main.ts` `onload()`:
  ```typescript
  async onload() {
    await this.loadSettings();
    
    // Check if migration needed
    if (this.needsMigration()) {
      // Show modal on first settings open
      this.pendingMigration = true;
    }
  }
  
  private needsMigration(): boolean {
    return !this.settings.hasTemplatesMigrated && (
      this.settings.outputTemplate !== undefined ||
      this.settings.inlineOutputTemplate !== undefined ||
      this.settings.multipleCardsOutputTemplate !== undefined
    );
  }
  ```

## Risks & Mitigations

**Risk 1: Migration fails**
- Mitigation: Keep old settings, add manual migration button

**Risk 2: Template folder detection wrong**
- Mitigation: Always show confirmation modal with browse option

**Risk 3: Custom template file deleted/moved**
- Mitigation: Graceful fallback to built-in + notice to user

**Risk 4: Performance (reading file on every draw)**
- Mitigation: Cache template content, invalidate on file change
